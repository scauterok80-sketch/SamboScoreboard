САМБО-СЕКРЕТАРЬ 3.0
Windows 10/11 x64. Полностью автономная работа без интернета.

НАЗНАЧЕНИЕ
Программа секретаря соревнований по спортивному и боевому самбо для турниров примерно от 50 до 250 участников.
Один спортсмен проходит единую цепочку: заявка -> комиссия по допуску -> взвешивание -> категория -> жеребьёвка -> поединки -> итоговое место -> протокол.

ОСНОВНЫЕ РАЗДЕЛЫ
1. Турнир: название, место, даты, ковры, главный судья, главный секретарь, схема командных очков.
2. Категории: дисциплина, пол, возраст, вес, система проведения, утешительная схема, способ жеребьёвки.
3. Участники: ФИО, дата рождения, пол, регион, организация, команда, тренер, разряд, дисциплина, возраст, вес.
4. Допуск: статусы Заявлен / Документы проверены / Допущен / Не допущен / Ожидает решения и причина решения.
5. Импорт Excel: стандартный шаблон, произвольные колонки с сопоставлением, предпросмотр, ошибки строк, нормализация ФИО, обработка дубликатов по одному: объединить / оставить обоих / отредактировать / пропустить.
6. Взвешивание: заявленный и фактический вес, контроль обычных и открытых (+/свыше) категорий, решение комиссии без автоматического переноса.
7. Судьи: ФИО, регион, судейская категория, роль; назначения по категории и ковру.
8. Жеребьёвка:
   - круговая 2-6;
   - смешанная только 5-7: 5=2+3, 6=3+3, 7=3+4, затем A1-B2 и B1-A2, два третьих места;
   - олимпийская 8/16/32 с корректными BYE без фиктивных встреч;
   - ручная, посев + автоматическое заполнение, полностью автоматическая;
   - опциональное разведение спортсменов одной команды;
   - предварительная жеребьёвка, перестановка/пережеребьёвка, утверждение и блокировка.
9. Олимпийские утешительные:
   - от финалистов;
   - от полуфиналистов;
   - без утешительных;
   вариант выбирается до жеребьёвки согласно Положению соревнования.
10. Поединки: внутренний порядок сетки, отдельный видимый номер, ковёр, плановое время, статусы Ожидает / Готов / Вызван / Идёт / Завершён.
11. Результат: счёт, оценки 4/2/1, классификационный результат 4:0 / 3:1 / 3:0 / 2:0 / 0:0, длительность, победитель, причина, фактические судьи.
12. Корректировки: изменение результата журналируется; зависимые непроведённые встречи перестраиваются, проведённые требуют ручного решения главного секретаря.
13. Итоги: круговая система с каскадом критериев и ручным решением ГСК при полном равенстве; смешанная и олимпийская системы; два третьих места; дисквалифицированные исключаются из личного места.
14. Ковры: текущая/следующая/ожидающие встречи, запрет двух одновременных схваток «Идёт» на одном ковре.
15. Протоколы: участники, мандатный протокол, пустое и заполненное взвешивание, судьи, пустые протоколы всех категорий, протокол категории, командный зачёт, сводный протокол, полный пакет соревнования.
16. Хранение: SQLite, сохранение каждого результата, журнал действий, автоматические резервные копии, архив турниров и восстановление незавершённого турнира.

ПРАВИЛА
Спортивная логика ориентирована на действующие российские Правила вида спорта «Самбо» (приказ №756 от 26.09.2025) с изменениями/разъяснениями, действующими с 01.09.2026.
Конкретный вариант олимпийского утешения выбирается согласно Положению конкретного соревнования.

БЕЗОПАСНОСТЬ ДАННЫХ
После утверждения жеребьёвки нельзя менять допуск, взвешивание или переносить спортсмена без разблокировки.
После проведения хотя бы одной схватки сетку нельзя стереть пережеребьёвкой.
Завершить поединок можно только через форму результата.
